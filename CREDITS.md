The forge headless live pass via `live_targets` and the Playwright "works headless" note were dropped. The `to-spec` return-without-publishing branch was dropped and replaced by a "Making it a step before a spec ships" section that runs `/persona-review #<spec>` standalone. The rules table gained a severity column and three new rules: `persona-unknown-avatar` (an unknown avatar is walked as the closest one), `persona-model-missing` (now listed, with medium severity and judgement fix) and `suspected-prompt-injection` (high, judgement). The locator is now `journey:<id>#step-<n>/<avatar-id>`, or `spec:<n\|path>#story-<n>/<avatar-id>`, and `journey` is unset for specs. The new `fix` rule makes only a jargon finding mechanical, and only when the avatars file names the replacement and the term sits in a UI string. `source` is `internal`, and unwritten page text is quoted verbatim and marked judgement. Interactive delivery offers product-modeling fixes for journey drift or missing avatar words. LIVE.md gained an "interactive only / What it needs" section and the prompt-injection stop-and-record rule, and no longer starts the app unless asked. Its browser fallback now accepts any browser tool. WALKTHROUGH.md gained a paragraph on walking a spec's user stories before anything is built. Added `persona-hidden-step` and `persona-journey-too-long` rules (LIVE.md names them), a note that the headless rotation stays put under dry-run, and the pre-spec step no longer mentions roles. |
