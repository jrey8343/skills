Call the Skill tool twice, for "grilling" and "domain-modeling".

When the grill's frontier is empty, close it: state every **pending** model change the session produced — each entry's full text, and the text it replaces — and name its **carrier**. Work to follow means telling the user to run `/to-spec`, which collects the entries verbatim. The decision itself as the deliverable means offering the docs-only PR that domain-modeling describes.
