# which-skill

## What it does

A router over the whole collection. Describe your situation and it points you to the skill or flow that fits: adoption, the idea-to-ship flow, the on-ramps, the audits, or a standalone tool.

It only orients; it never runs anything itself. It reads the relevant `SKILL.md` before claiming what a skill does.

## When to reach for it

You invoke this by typing `/which-skill`. Reach for it whenever you can't remember which skill applies, or want to see how they chain. For the long-form map with diagrams, read [WORKFLOWS.md](../WORKFLOWS.md).

## It's working if

- You can describe a situation in plain words and get one skill back, with the reason.

## Where it fits

The map itself. Every docs page points here.
